# Python Discovery Piscine - 42 Penang

Welcome to my repository for the **Python Discovery Piscine** at **42 Penang**. This repository contains solutions and code exercises covering fundamental to intermediate Python programming concepts through a hands-on, module-based curriculum.

---

## 📝 Description

The **Python Discovery Piscine** is an intensive, self-paced learning bootcamp designed to build a solid foundation in Python. Across 10 comprehensive modules (Module 00 through Module 09), this repository covers essential programming paradigms, data structures, algorithms, object-oriented programming (OOP), file handling, error management, and practical application development.

Each module focuses on core Python principles, progressing from basic syntax to structured software engineering practices required within the 42 Network methodology.

---

## 🛠️ Tech Stack & Requirements

* **Language:** Python 3.x
* **Operating System:** Linux / macOS / WSL
* **Style Guide:** Standard Python coding conventions (PEP 8)
